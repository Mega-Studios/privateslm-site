Write a product description

Prompt library · Writing

Benefits first, facts kept.

The prompt

Write a product description for [product] for [where it will appear]. Facts: [features, sizes, materials, price]. Lead with what it does for the buyer, keep every fact exact, and write a 20-word version too.

Tips

  • Add a photo of the product for details it can see.
  • Ask for SEO keywords to include.

Use it in Omnimo

Open a new chat in Omnimo, paste the prompt, replace the parts in [brackets] and send. The free models handle this well; for something long or important, switch to a flagship and compare.
