Rewrite a document in plain language

Prompt library · Documents

Legal or technical text, made readable.

The prompt

Rewrite the attached document in plain language for someone with no background in [field]. Keep every obligation, number and date. Put the most important thing first. Under [number] words.

Tips

  • Ask for the original wording next to each point you're unsure about.

Use it in Omnimo

In a chat in Omnimo, attach the file (PDF, Word, Excel, PowerPoint, Pages or a scan), then paste the prompt. The file is read on your device; its text goes to the model you picked.
